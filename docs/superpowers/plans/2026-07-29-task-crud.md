# タスク管理CRUD完成 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `Task`モデルに対する新規作成・編集・削除を実装し、タスク管理CRUDを完成させる。

**Architecture:** 全ビューを関数ベースビュー(FBV)に統一し、関数名/テンプレート名/URL名を一貫させる(`.claude/instructions.md`の「View Naming Rules」参照)。フォームは`app/forms/task.py`の`TaskForm(ModelForm)`を新規作成・編集で共用する。

**Tech Stack:** Django 6.0 (FBV, ModelForm, messages framework), pytest-django (unit test, `client`フィクスチャ), pytest-playwright (E2E)

## Global Constraints

- ビューは関数ベースビュー(FBV)のみ。クラスベースビューは使わない。
- 関数名はテンプレートファイル名と一致させる: `index` / `show` / `new` / `edit` / `delete`
- URL名は `<モデル名>_<関数名>` とする: `task_index` / `task_show` / `task_new` / `task_edit` / `task_delete`
- `app/views/__init__.py`はモジュール単位でインポートする(`from . import home, task`)。個々の関数をフラット再エクスポートしない。
- `app/urls.py`は`views.task.show`のようにモジュール修飾で参照する。
- 認証・権限チェックは対象外(スコープ外)。
- **本作業ではユーザーの指示によりコミットを一切行わない。** 各タスク末尾に本来あるべき`git commit`ステップは実施しない(該当箇所に明記する)。
- 参照仕様書: `docs/superpowers/specs/2026-07-29-task-crud-design.md`

# タスク編集
def edit(request, pk):
    task = get_object_or_404(Task, pk=pk)
    if request.method == 'POST':
        form = TaskForm(request.POST, instance=task)
        if form.is_valid():
            form.save()
            messages.success(request, 'タスクを更新しました。')
            return redirect('app:task_show', pk=task.pk)
    else:
        form = TaskForm(instance=task)
    return render(request, 'app/task/edit.html', {'form': form, 'task': task})
