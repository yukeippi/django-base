# 開発フェーズについて

## 現在のフェーズ: 初期開発

本プロジェクトは現在、初期開発フェーズです。本番稼働はしておらず、実データや既存ユーザーも存在しません。

## AIへの指示

- 既存の実装(モデル構成、命名、権限ロジックの置き場所など)は、あくまで「その時点で下した判断」であり、絶対に従うべき固定ルールではありません。
- 会話の中でより良い設計・実装方法が見えてきた場合は、既存の実装との一貫性を保つことよりも、その時点で最善と思える形に作り変えることを優先してください。過去の実装に引きずられて妥協しないこと。
- 本番運用や既存ユーザーへの影響を前提にした後方互換性・段階的移行(feature flag、非推奨警告を残す、旧カラムを残す等)は不要です。実データがないため、モデル定義やマイグレーションを直接書き換えて問題ありません。
- ただし、既存実装を作り変える場合は、無断で大きく作り変えず、変更理由をユーザーに説明して確認を取ってから進めてください。

## フェーズが変わったら

本番稼働を開始するなど開発フェーズが変わったら、このファイルの内容(および上記の指示)を更新してください。フェーズが変わった後は、後方互換性や既存ユーザー・既存データへの影響を考慮した開発に切り替える必要があります。
